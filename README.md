# VIT New Gate Street Design Using Unity

## Project Overview
This project aims to create a 3D representation of VIT New Gate Street using Unity. Different materials and streetlights are used to improve the visual appearance and realism of the scene.

## Objectives
- Design VIT New Gate Street in Unity 3D.
- Apply different materials and textures to the road and surrounding objects.
- Add streetlights and configure lighting.
- Explore 3D environment design and lighting techniques.

## Software Used
- Unity 3D
- C#
- Materials and textures
- Unity lighting system

## Main Features
- 3D street environment
- Different road and object materials
- Streetlights and illumination
- Realistic scene design

## How to Run
1. Download or clone this repository.
2. Open the project through Unity Hub.
3. Open the main scene.
4. Press Play to view the environment.
